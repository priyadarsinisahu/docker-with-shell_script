# docker-with-shell_script

Docker Management Utility

Purpose: Practice Docker + Shell Scripting

Instead of memorizing Docker commands separately, build one Bash script that works like a Docker management utility:

docker-manager.sh
        │
        
        ├── install Docker
        
        ├── start Docker
        
        ├── stop Docker
        
        ├── restart Docker
        
        ├── status
        
        ├── pull image
        
        ├── list images
        
        ├── run container
        
        ├── list containers
        
        ├── stop container
        
        ├── start container
        
        ├── restart container
        
        ├── logs
        
        ├── exec into container
        
        ├── remove container
        
        ├── remove image
        
        ├── prune unused resources
        
        └── uninstall Docker
